# About this project

**IEEE RAS AI & Robotics Knowledge Base** is a proposed documentation and learning initiative for the AI & Robotics team.

The goal is to combine onboarding, educational materials, and repeatable project documentation in a single maintainable platform.

**Prototype status:** This website is an initial demonstration and does not claim to be an officially published IEEE RAS resource until approved by the relevant team.
