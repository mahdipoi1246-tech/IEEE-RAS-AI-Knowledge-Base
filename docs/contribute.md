# Contribute to the Knowledge Base

Everyone can improve the knowledge base, subject to team review.

1. Create or claim a **GitHub Issue** describing your change.
2. Create a feature branch from `main`.
3. Edit the relevant Markdown page and test your code samples.
4. Run `python -m mkdocs build --strict` locally.
5. Open a **Pull Request**, complete the checklist, and request review.
6. Merge after review and passing checks.

## Content standards

- Explain the objective and prerequisites.
- Prefer short, runnable examples over unsupported claims.
- Cite authoritative references and verify external links.
- Label unverified project information as **Pending**.
- Never commit passwords, API keys, private member data, or confidential files.
- Respect software licenses and image rights.

See `CONTRIBUTING.md` in the repository for more information.
