# Getting Started

## Before you begin

Install [Python](https://www.python.org/downloads/), [Git](https://git-scm.com/downloads), and [VS Code](https://code.visualstudio.com/).

Open a terminal and verify:

```bash
python --version
git --version
```

On Windows, `py --version` may work if `python --version` does not.

## Your first contribution

1. Read [Git & GitHub](git.md).
2. Pick an open documentation Issue.
3. Create a branch and edit a Markdown page.
4. Open a Pull Request and request review.

**Checkpoint:** You can open a terminal, run Python, and explain what a Pull Request is.
