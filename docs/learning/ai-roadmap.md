# AI & Robotics Learning Roadmap

## Stage 1 — Foundations

Python basics, Git & GitHub, basic algebra, working with data.

**Deliverable:** A small Python program and your first Pull Request.

## Stage 2 — Machine Learning

Datasets, train/test split, classification, evaluation metrics, and scikit-learn.

**Deliverable:** A documented classifier with evaluation results.

## Stage 3 — Computer Vision

Image processing, OpenCV, camera calibration, object detection.

**Deliverable:** A simple object-tracking demo.

## Stage 4 — Robotics AI

Sensors, motion control, ROS 2 concepts, perception and decision-making.

**Deliverable:** A team-reviewed robotics integration project.

!!! tip "Keep it practical"
    Every learning track should link to at least one hands-on exercise or documented project.
