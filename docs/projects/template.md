# Project Documentation Template

Copy the following outline when adding a new project.

```markdown
# Project Name

## Overview
What problem does it solve?

## Team & Status
Owner, contributors, last review date, current state.

## Hardware
Exact component names, specifications, bill of materials.

## Software
Languages, versions, dependencies, code repository.

## Architecture & Wiring
System diagram, pinout, connection details.

## Setup
Reproducible step-by-step instructions.

## Testing & Results
Test procedure, expected and observed results, evidence.

## Known Issues & Future Work
Limitations, planned improvements.

## References
Official manuals, source repositories, external citations.
```
