# Contribution Guidelines

1. Open an Issue for your proposed change.
2. Branch from `main` (`docs/short-description`).
3. Write concise Markdown and test any included code.
4. Run `python -m mkdocs build --strict`.
5. Open a Pull Request and complete the review checklist.
6. Wait for approval before merging.

Never upload private credentials, sensitive team data, or third-party copyrighted content without permission.
